# 小鲸鱼

给自己群写的 QQ 机器人，一只住在群里的蓝色小鲸鱼。

平时在群里瞎聊、玩梗、偶尔损人一句；真问正经问题的时候又挺靠谱。

## 她都会啥

- **聊天** —— 群里 @ 她，或者私聊。说话短，尽量不像机器人。
- **看图片** —— 先发图，再 @ 她问。图发完 3 分钟内 @ 就行，不用和 @ 挤在一条消息里。
- **联网查东西** —— `/搜 要查的内容`。查完她自己判断要不要配张图，该配就顺手发过来，不该配就不发。
- **画图** —— `/画 想要什么`，或者直接说「给我生成一张 XX」。1080p。画具体角色之前会先上网核一下长什么样，不然画出来只能算「神似」。
- **找现成的图** —— 「给我发张奶龙的图」「找张壁纸」，她直接上网找几张发过来。注意和「画」是两回事。
- **发表情包** —— 情绪到了她会顺手甩一张，也可以 `/表情 委屈` 这样指名要。表情包是本地库，自己往里丢图就行。
- **忘记** —— 发 `重置`，这个会话的聊天记录清空。

### 群里的功能命令

这些不用 @ 她也能用，发 `/帮助` 能看全。

- **骰子 / 抽签 / 运势** —— `/骰 2d6`、`/抽签`、`/运势`。本地随机，不花 token。
- **签到积分** —— `/签到` 每天领分，连续签到多给点。`/积分` 看自己，`/排行榜` 看群里的。
- **小游戏** —— `/猜数字`（然后 `/猜 50`，猜中 +5 分）、`/成语接龙`（用哪个字开头她就说，直接发四个字，`/结束` 退出）。
- **定时提醒** —— `/提醒 20分钟后 开会`，到点她 @ 你。`/提醒列表`、`/取消提醒 3`。重启也不会丢。
- **天气 / 热搜** —— `/天气 杭州`（不给城市就用 `default_city`）、`/热搜` 看百度实时热搜。
- **入群欢迎 / 防撤回** —— 新人进群自动欢迎；有人撤回消息，她把撤回前的内容贴出来。
- **复读接梗** —— 群里连着刷同一句话，她跟着来一句（同一句只接一次，不刷屏）。
- **群管** —— `/禁言 @某人 10分钟`、`/全体禁言`、`/解除禁言`、`/踢 @某人`。
  这个只有群主/管理员能用，而且机器人自己得是群管理；不放心就把 `admin_cmds` 关掉。
  踢人**不用非得打斜杠命令，说人话也认**：「把这个人踢了」「踢了他」「把他踢出去」都行。
  指认对象四种都认：**@ 他**、**引用他那条消息**、直接把**名字打出来**（比群名片/昵称）、
  说「**我**」（=说这话的人自己）。都认不出它会反问「踢谁?」，不会瞎猜。
  另外机器人只能动**普通成员**：踢不动、也禁不了群主和其他管理员。原因是踢人这个动作是
  **机器人这个号**发出去的，QQ 只认这个号自己的身份——它顶多是个管理员，只有群主才压得住管理员，
  而机器人当不了群主。这种情况它会直接把原因说清楚，不会假装踢成功了。
- **自动禁言刷屏** —— 同一个人 15 秒内连着刷 6 遍同一句话（单条 ≥4 字），自动禁言 10 分钟，
  并在群里说一句「别刷了 先歇 10 分钟」。这是**硬规则，不交给模型判断**——
  踢人拉不回来，禁言到点自己会解，所以只做到禁言这一层。
  群里好几个人一起复读同一句（接梗）不算刷屏；群主/管理员/`admin_users` 一律不动；
  一天最多禁 10 个人。阈值都在 `spam_*` 那几个配置里，嫌严就把 `spam_count` 调大。
- **群统计** —— `/统计` 看今天这个群聊了多少条、谁最活跃、几点最热闹。
- **余额** —— `/余额` **三个地方都查**：DeepSeek 官网还剩多少钱（问 `/user/balance`）、
  阿里云账户还剩多少（现金走 `QueryAccountBalance`，优惠券走 `DescribeCoupon`，学生那 300 元就在券里）、
  百炼那几个模型还剩多少免费 token 额度（`bl usage free`）。都是问官方接口，不是自己估的。
  哪一段没配 key 就自动不显示，不会报错。
- `aliyun_access_key_id` / `aliyun_access_key_secret` —— 查阿里云现金和那 300 元优惠券要用的 RAM 密钥。
  **注意这是第三套密钥**，跟百炼的、DeepSeek 的都不同。留空 = 不查阿里云这一段。
  建议用子账号、只给 `bss:DescribeCoupons` 和 `bss:QueryAccountBalance` 这两条权限，见下面「怎么用起来」第 8 条。

群聊默认用 `smart` 那档：**@ 她、或者直接叫她的名字（`bot_names` 里那几个），一定会回**；
没人叫她的时候也有小概率自己搭一句（`chime_chance`，默认 8%），但插过话后有 `chime_cooldown` 秒冷却、
夜里 `quiet_hours` 不吭声、被冷落够了也不往上凑，所以不会变成刷屏怪。
想回到「只理 @」的老规矩，就把 `group_trigger` 改成 `at`。
群里别人没点她的闲聊，她只听不答（当上下文背景），所以她知道群里刚在聊什么。

### 那些让她「像个群友」的小设计

- **分段回话** —— 回复长了会自动拆成两三条发，像人一句句打，不是糊一大块。第一条会引用你那句。
- **长期记忆（轻量版）** —— 聊天按会话存档到 `memory.json`，你提以前的事时她会翻出来。
  没上向量库，就是存文本 + 关键词比对，够用且不花钱。
- **主动冒泡** —— 群里安静 45 分钟以上，她会自己说一句（接刚才的话头或者随口问）。
  `quiet_hours` 是免打扰时段，默认 23:00~08:00 不出声。
- **群聊日报** —— 每天 21:00 自动发一份：今天聊了啥、名场面、谁最活跃。
  想关就把 `daily_report` 设成 false。
- **偷表情包** —— 群里别人发的表情包，她会让识图模型看一眼，是表情包就收进自己库里、
  顺手打好情绪和使用场景的标签，下次聊天就能用上。同一张要**被发到两次以上**才收
  （`steal_min_seen`），这样截图、照片、商品图基本进不来。每天最多偷 8 张（`steal_max_per_day`）。
- **出门前洗一遍** —— 模型爱吐 markdown、bullet、「好的，我帮你看看」这种客服腔，
  还有「（挠头）」这种动作描写。QQ 里 markdown 根本不渲染，所以发出去之前代码会洗一道：
  拆标记、砍客服腔、删动作描写、超长截断（`reply_max_chars`，默认 300 字）。
  波浪号「~」是故意留着的，那是她的语气。
- **被冷落就闭嘴** —— 她说完话之后，如果群里连着 5 条（`sulk_after`）没人接她那茬，
  就不再主动冒泡了，等你下次叫她。
- **空 @ 也理人** —— 只 @ 她一下、什么字都没打，她会回一句「怎么了？」/「？」/「嗯？」/「干啥？」。
- **关键词小仪式** —— 「早上好」「晚安」「生日快乐」这类词命中后，会给这一轮回复带个方向
  （比如早安就随口打个招呼）。写在 `keyword_reactions` 里，自己加词就行。
- **失败也不装死** —— 模型接口炸了、图取不到的时候，她会说一句「网卡了，重发一遍…」
  再甩张表情包，不会让你对着空气等。

### 文字聊天可以单独接一家

默认所有能力走同一个端点（`deepseek_base_url` + `deepseek_api_key`）。但文字聊天可以单独拎出去：

```json
"chat_base_url": "https://api.deepseek.com",
"chat_api_key": "sk-你的key",
"chat_model": "deepseek-v4-pro",
"chat_thinking": false
```

`chat_api_key` 填了，**只有文字聊天**（包括日报、冒泡这些小调用）走这个端点；识图、联网搜索、
生图都留在原端点。搜索试过换成百炼的 DeepSeek——它认 `enable_search`、实测也搜得到，但那是
pro 档，按量计价比 flash 贵，所以搜索还是用回 `qwen3.8-flash`。

几个容易踩的点：

- 官网的**思考模式默认是开的**，`chat_thinking: false` 会显式发 `thinking: {"disabled"}`。
  不关的话群里聊天又慢又费钱（推理的 token 也计费）。
- 官网只认 `deepseek-flash`（1 元/2 元）和 `deepseek-v4-pro`（3 元/6 元），
  老名字 `deepseek-chat` / `deepseek-reasoner` 已经弃用（价格是每百万 tokens，输入/输出）。
- 官网不认百炼那套 `enable_thinking` / `enable_search`，所以走官网时这两个参数不会发出去。
  往官网传 `tools: web_search` 会被 **422** 拒掉（它只认 `function` 类型），所以官网搜不了。
- **百炼的 DeepSeek 默认也开着思考**，要是哪天把搜索模型换成 `deepseek-*`，那条路必须显式
  `enable_thinking: false`，不然 `max_tokens` 会被思考烧光、正文变成空字符串（这坑踩过）。
- 搜索的答案是把资料揉进去讲，比闲聊长，所以搜索时不受 `reply_max_tokens` 那个 120 的限长，
  改用 `max_tokens`，不然会拦腰断在半句。
- `chat_api_key` 留空 = 一切照旧，等于没配。想切回来把 key 清掉就行。

`/余额` 会跟着变：接去官网之后，它会**分两段**报——上面一段是官网余额（按量扣费），
下面一段才是阿里云那边的免费额度。

## 怎么跑的

```
QQ
 └── NapCatQQ      注入 QQ，负责收发消息
      └── bot.py   ← 这个仓库，就一个文件
           └── 大模型    OpenAI 兼容接口
```

`bot.py` 干的事其实很简单：收到消息 → 按内容挑一个模型问一句 → 把结果发回群里。

人设写在 `config.json` 里，但「什么时候该画图」这类规矩我塞进代码了。这样以后改人设随便改，
不会一不小心把功能改坏——这个坑我踩过。

## 文件都是啥

- `bot.py` —— 全部逻辑，就这一个文件
- `config.example.json` —— 配置模板，复制一份改名叫 `config.json` 再填
- `requirements.txt` —— 依赖（websockets / httpx / Pillow）
- `启动.bat` —— 一键拉起 NapCat + 在窗口里画二维码 + 机器人
- `二维码.py` —— 把 NapCat 的登录码画在终端里，手机对着屏幕扫；`二维码.bat` 是它的外壳
- `登录余额.bat` —— `/余额` 的登录态过期时，双击这个重新授权一次
- `表情包/` —— 表情包库，图放在这一层，标签写在 `tags.json` 里
- `data.json` —— 积分、签到、待提醒的事，跑起来自己生成（已 gitignore）
- `memory.json` —— 长期记忆的聊天存档，也自己生成（已 gitignore）
- `NapCat/` —— 别人写的程序，得自己去下，没放进仓库

## 怎么用起来

1. 装依赖：`pip install -r requirements.txt`
2. 下 NapCatQQ 解压到 `NapCat/`，第一次要用管理员权限跑一遍，然后扫码登录 QQ
3. 在 NapCat 的 WebUI 里开一个正向 WebSocket，端口跟 `onebot_ws_url` 对上
4. `copy config.example.json config.json`，把 Key 填上
5. 双击 `启动.bat`
6. 想用 `/余额` 查免费额度的话，再装一个阿里云百炼的官方命令行（一次性的事）：

   ```
   irm https://bailian.aliyun.com/cli/install.ps1 | iex
   bl auth login --console
   ```

   第二条会开浏览器，登录阿里云账号点一下授权。登录态会过期，过期后 `/余额` 会提醒你，
   双击 `登录余额.bat` 重新登一次就行。不装也不影响别的功能，`/余额` 会直接说没找到工具。

`config.json` 里有 Key，所以我把它写进 `.gitignore` 了，别手滑传上去。

## 配置里比较要紧的几项

- `onebot_ws_url` —— NapCat 的地址
- `deepseek_base_url` / `deepseek_api_key` —— 模型服务和 Key，OpenAI 兼容的都能用
- `model` —— 百炼那边的兜底聊天模型（`chat_api_key` 没填时就靠它）
- `vision_model` —— 看图的模型
- `search_model` —— 联网用的（flash 档就够，pro 档搜得到但按量更贵）
- `image_model` —— 画图用的
- `draw_prompt_model` —— 画图前扩写描述、顺便核对角色长相的
- `reply_max_tokens` —— 聊天回复的长度上限（搜索那条路不受这个限制）
- `max_history` —— 每个会话记多少轮
- `recent_image_seconds` —— 图片「保鲜期」，过了就不认了
- `sticker_chance` —— 模型想发表情包时，真正发出去的概率（不然每条都发就刷屏了）
- `group_trigger` —— `smart`（默认：被叫必回，没人叫也可能搭一句）/ `at`（只理 @ 和点名）/
  `prefix`（只理带 `group_prefix` 的）/ `all`（每条都回）
- `bot_names` —— 别人怎么叫它算「点名」。默认 `小鲸鱼` / `鲸鱼` / `小鲸` / `鲸鲸`，
  写进去的词一出现就必须回，所以别放太常见的词
- `chime_chance` / `chime_cooldown` —— 没人叫时插话的概率、两次插话至少隔多少秒
- `default_city` —— `/天气` 不带城市时用哪个
- `admin_cmds` / `admin_users` —— 群管命令开关；`admin_users` 里写死几个 QQ 号也能用
- `auto_mute_spam` / `spam_count` / `spam_window` —— 刷屏自动禁言：多久内、刷几遍同一句算刷屏
- `spam_min_chars` / `spam_mute_seconds` / `spam_mute_max_per_day` —— 多短的话不算、
  禁多久、一天最多禁几个。`auto_mute_spam` 设 false 就只记录不动作
- `welcome_text` / `recall_notice` / `repeat_enabled` —— 入群欢迎语、防撤回、复读接梗的开关
- `split_reply` / `quote_reply` —— 长回复分段发、回复时引用原消息
- `memory_days` / `memory_recall` —— 长期记忆存多少天、每次捞几条
- `proactive` / `proactive_idle_minutes` / `quiet_hours` —— 主动冒泡的开关、冷场多久才说话、免打扰时段
- `steal_stickers` / `steal_max_per_day` —— 偷表情包的开关和每天上限
- `daily_report` / `report_time` —— 群聊日报的开关和发送时间
- `system_prompt` —— 人设。**写法有讲究，见下面「人设怎么写才像真人」**
- `temperature` —— 0.75 左右。调高会更跳、更容易说岔；调低会变呆、开始车轱辘话
- `safe_domains` —— 域名白名单，不在名单里的图片一律不下载
- `ref_image_enabled` —— 画角色时要不要先用参考图引导，像不像基本靠它

### 人设怎么写才像真人

第一版人设我写了 500 多字，90% 在描述「蓝头发、鲸尾、吃白饭」——
**群里又看不到她长什么样**，这些字纯粹在稀释模型的注意力，结果就是它记人设记了半天，
说起话来反倒像个客服。

后来改成两段结构，效果差别很大：

```
## 你是谁        ← 一句话交代身份，别展开
## 怎么说话(最重要) ← 全是"习惯"：几句、多少字、标点怎么打、什么口头禅、禁用什么句式
## 什么时候正经   ← 认真问事时收起懒散，答案要准
## 例子           ← 8 条真实对话样例
```

**关键在最后的「例子」**。给模型看几条"你会怎么回"，比你写一万字设定都管用——
它是在语言概率空间里模仿，不是真的理解人设。所以：

- 例子要**短**，跟你想要的长度一样（你给 30 字，它就会回 30 字）
- 例子要**覆盖你常遇到的场景**：被叫、被夸、被损、认真提问、闲聊
- 想要哪条规矩，就把它写得更强烈、占的字数更多，否则容易被忽略
- 少写外貌，多写行为习惯（"被逗就损回去"比"她有一头蓝发"有用得多）

`temperature` 建议 0.5~0.8：太低会复读同几句，太高会出戏。

### 为什么要好几种模型

因为要的东西不一样。聊天想要快，画图想要画质，搜索想要准，看图得能看图。
用一个模型全包的结果就是哪样都不太行，所以干脆分开，各挑各的。

聊天那档默认用 `deepseek-flash`（输入 1 元 / 输出 2 元，每百万 tokens），
想更聪明就换 `deepseek-v4-pro`（3 元 / 6 元）。注意**填模型名要填官方 API 认的名字**，
写别的（比如 `DeepSeek-V4.1-Flash`）会直接被拒 400，表面上就像是"她变傻了"。
拿不准就 `GET /models` 问一下你的 key 认哪些名字。

## 安全上做了两件事

**域名白名单。** 图片只从 `safe_domains` 里列出来的站点下载，其余直接拒绝，请求压根不发出去。
所以让她搜东西的时候，不会莫名其妙点到什么奇怪的站。

**Key 不外传。** `config.json` 被 git 忽略，仓库里只有一份占位符版本的 `config.example.json`。

## 踩过的坑

**QQ 一闪就没了 / NapCat 注入不上。** `loadNapCat.js` 得和 QQ 主程序放一个目录，
而且启动 NapCat 要给管理员权限，不然钩子挂不上。

**发图 @ 她，她没反应。** 大概率是图和 @ 是两条消息。代码里记了最近发的图，
`recent_image_seconds` 时间内追问都还算数。改这个值就能调保鲜期。

**回复太长、一眼就是 AI。** 现在聊天回复有句数和字数限制，也禁掉了「作为AI」
「希望以上内容对您有帮助」这类客服腔。改 `system_prompt` 的时候注意别把这几条覆盖掉——
不过它们本来就在代码里，你改人设也动不到。

**她突然变傻 / 不理人。** 先看控制台有没有报 400。多半是 `chat_model` 填了个 API 不认的名字
